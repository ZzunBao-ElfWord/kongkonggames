用户平台行为守则

规范平台社交互动、陪玩服务、线上沟通等各类使用行为

为维护本平台健康、文明、合规的网络服务秩序，保障全体用户、陪玩师的合法权益，规范平台社交互动、陪玩服务、线上沟通等各类使用行为，依据《网络信息内容生态治理规定》《未成年人网络保护条例》等相关法律法规，制定本行为守则。

一、通用基础行为规范（全体用户遵守）

  • 1. 所有用户必须完成真实实名认证，严格遵守国家网络安全及互联网服务相关法律法规，文明上网、理性互动。
  • 2. 用户在平台发布文字、语音、图片、评论、动态、私信等一切内容，必须真实合法、积极健康，严禁制作、复制、发布、传播违法违规及不良信息，包括但不限于危害国家安全、涉政敏感、色情低俗、暴力血腥、辱骂诽谤、造谣传谣、歧视引战、封建迷信、赌博诱导等违规内容。
  • 3. 严禁任何形式的诈骗、刷单、恶意薅羊毛、虚假交易、私下交易、有偿代练违规推广等行为。
  • 4. 尊重他人合法权益，严禁骚扰、辱骂、恐吓、诋毁、人肉搜索、曝光他人隐私信息，禁止侵犯他人肖像权、名誉权、隐私权及知识产权。
  • 5. 禁止使用外挂、脚本、漏洞、非法工具等非正常手段操作账号、刷取数据、恶意卡单、违规获利，禁止批量注册、倒卖、租借、转让平台账号。
  • 6. 未成年人需严格遵守青少年模式规则，严禁冒用成年人身份规避监管。

二、下单用户行为规范

  • 1. 用户下单陪玩服务前，需如实确认服务需求，遵守平台订单规则与服务约定，文明沟通、礼貌互动。
  • 2. 严禁恶意下单、无故频繁取消订单、恶意差评、故意刁难陪玩师。
  • 3. 服务过程中不得提出低俗、色情、擦边、违规及超出平台合规范围的不合理服务要求。
  • 4. 严禁利用陪玩服务进行炒作、引流、外站推广、拉群私域导流等非合规操作。

三、陪玩师服务行为规范

  • 1. 陪玩师接单服务需严格遵守平台服务标准，诚信履约、文明服务。
  • 2. 严禁出现低俗话术、擦边互动、色情暗示、言语挑逗、辱骂用户等违规服务行为。
  • 3. 严禁以任何理由诱导、引导用户私下转账、线下交易、外站充值。
  • 4. 不得虚假接单、挂单不服务、恶意卡单、串通用户刷单刷评。
  • 5. 严格遵守平台青少年保护规则，不得向未成年人提供任何付费陪玩服务。

四、禁止行为与违规处置

  • 1. 全体用户严禁触碰平台红线行为，包括但不限于涉黄涉暴、涉赌涉诈、违法引流、私下交易、恶意扰乱平台秩序、冒用身份违规操作、侵犯他人权益等行为。
  • 2. 平台将根据用户违规情节轻重，采取警告、内容删除、限制发言、限制下单接单、冻结账号功能、封禁账号、清空违规收益等处置措施。
  • 3. 用户若发现平台内违规内容、违规用户、恶意行为，可通过平台举报通道反馈。

五、附则

  • 1. 本行为守则为平台用户服务协议配套规则，与平台各项协议、规则具有同等法律效力。
  • 2. 平台有权根据法律法规更新、运营需求，适时修订本守则。
