空空电竞隐私保护政策

更新日期：2026年10月16日 · 生效日期：2026年10月16日

个人信息是用户合法权益的重要组成部分，对每一位使用空空电竞产品与服务的用户而言至关重要。厦门精灵跳动科技有限公司（以下简称"我们"）始终恪守合法、正当、必要、诚信的个人信息处理原则，严格遵循《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国电子商务法》等相关法律法规要求，建立完善的个人信息安全保护体系，全方位保障广大用户（以下简称"您"）的个人信息安全与隐私权益。

为让您清晰、全面地知晓我们在您使用空空电竞、空空电竞小程序及相关衍生服务过程中，对您个人信息的收集、使用、存储、共享、披露等全部处理规则，同时明确您所享有的个人信息管理权利与维权途径，我们特制定本《空空电竞隐私保护政策》（以下简称"本政策"）。本政策将系统说明个人信息处理的全流程规范、用户权益保护细则、未成年人专属保护机制、政策更新规则及沟通渠道等核心内容。

特别告知：在您注册、登录、浏览、使用空空电竞全部产品及各项服务前，请您仔细阅读、充分理解本政策全部条款，其中加粗、下划线等重点标识内容为核心权责条款，请您重点知悉。您主动注册账号、登录平台并持续使用我们产品与服务的行为，即代表您已认真阅读、完全理解并无条件同意本政策全部内容。若您对本政策任意条款存在异议、无法接受，请您立即停止使用空空电竞所有产品及相关服务。

本政策将为您清晰解读以下十大核心板块内容：

  • 1. 核心术语定义与政策适用范围说明
  • 2. 个人信息收集与合法使用的全部场景及规则
  • 3. Cookie、缓存技术及第三方页面服务的使用规范
  • 4. 个人信息共享、转让、公开披露的合规标准与例外情形
  • 5. 个人信息安全存储机制、保护措施与留存期限
  • 6. 用户个人信息自主管理的全部合法权利及操作方式
  • 7. 未成年人个人信息专属保护规则与监护机制
  • 8. 本隐私政策的修订、更新与告知机制
  • 9. 咨询、投诉、维权的官方沟通渠道
  • 10. 法律适用与争议解决的通用规则

一、核心术语定义与政策适用范围

（一）核心术语定义

1. 空空电竞产品及关联服务：指由厦门精灵跳动科技有限公司（注册地址：厦门市）及其合法关联主体自主运营、官方发布的全部产品与服务体系，包含空空电竞客户端、空空电竞官方公众号、空空电竞官方网站、通过SDK、API、APK等技术形态提供的各类软件服务，以及后续迭代上线的全新产品、功能与服务形态。

2. 关联主体：指当前及未来直接或间接控股厦门精灵跳动科技有限公司、被厦门精灵跳动科技有限公司控股，或与本公司受同一主体控制的各类企业、机构及法人主体。

3. 未成年人：依据国家法律规定，指年龄未满十八周岁的自然人。其中，十六周岁以上、能够以个人劳动收入作为主要生活来源的未成年人，依法视为完全民事行为能力人。

4. 儿童：特指年龄未满十四周岁的未成年人，属于需要重点保护的未成年群体。

（二）政策适用范围

本政策全面适用于厦门精灵跳动科技有限公司旗下所有空空电竞系列产品及配套服务。若我方关联企业的产品、服务搭载、接入空空电竞核心技术或服务模块，本政策同样适用于该部分服务的个人信息处理行为。同时，本政策明确不适用于以下三类场景：

  • 1. 为空空电竞产品提供广告投放、营销推广服务的第三方机构，其独立开展的个人信息收集与处理行为；
  • 2. 空空电竞产品内嵌入的第三方网页、应用、服务模块，该类第三方独立运营的服务内容及个人信息处理规则，由第三方隐私政策约束；
  • 3. 非我方自主提供、未经我方授权的第三方产品、服务及相关内容。

二、个人信息收集与合法使用规则

我方严格遵循"最小必要、按需收集、合法合规"原则，将收集的用户个人信息划分为基础必备信息与拓展可选信息两类：

  • 1. 基础必备信息：为保障空空电竞产品核心功能正常运行、满足法律法规监管要求所必需收集的信息，您若拒绝授权提供，将无法正常使用平台核心服务与基础功能；
  • 2. 拓展可选信息：为实现您主动选择的拓展功能所需要的非必需信息，您可自主选择是否授权提供，拒绝授权仅会导致对应拓展功能无法使用，不会影响产品基础功能的正常使用。

因空空电竞产品服务场景丰富、功能模块多元，不同用户使用的功能、服务存在差异，具体信息收集范围以用户实际使用的产品功能为准。

（一）账号注册与授权登录场景

1. 自主账号注册：您在空空电竞平台注册专属账号时，需主动提供实名手机号码及短信验证码，同时可自主完善头像、昵称、登录密码、性别、生日等基础账号信息。其中，手机号码、短信验证码、性别、生日均属于敏感个人信息，我方基于网络实名制法律法规要求收集，用于核验用户身份、判定用户年龄层级、匹配基础服务资源。

生日信息主要用于核验用户是否年满十八周岁，严格落实未成年人服务管控要求；性别信息用于优化基础服务匹配、提升用户使用体验。您有权拒绝提供上述敏感信息，但将无法完成账号注册、正常使用平台服务。

账号注册完成后，您可自愿填写主页信息，自主发布动态、完善游戏或服务名片，该类信息完全由用户自主选择填写，不填写不影响平台基础功能使用。您的账号ID、昵称、头像、粉丝数、获赞数、发布动态等主页公开内容，默认可被平台其他用户查看，您可通过APP隐私设置功能，对未关注用户隐藏个人主页内容。

2. 运营商一键登录：我方与三大运营商达成合作，开通手机号一键登录服务。经您主动授权后，可直接调用设备本机号码完成账号注册与登录，无需手动输入验证码。您可自主选择放弃该功能，通过传统注册、登录方式使用平台服务。

（二）实名认证与人脸核验场景

为落实网络实名制监管要求、防范电信网络诈骗、保障平台交易安全、保护未成年人合法权益、规避账号冒用及违规操作风险，用户在使用部分专属功能时，需完成实名认证与人脸一致性核验，相关姓名、身份证号、人脸影像均属于敏感个人信息。

1. 智能人脸识别核验：用户申请主播开通、服务资质认证、资金提现、未成年人模式退出、账号封禁申诉等功能时，可通过平台接入的第三方人脸识别系统完成核验。经您授权后，平台及第三方服务机构将调用设备摄像头，采集人脸图像、视频及面部特征信息，结合您填写的姓名、身份证号码，完成身份一致性比对核验。第三方机构将核验结果及必要核验影像同步至我方，用于留存备案、处理用户争议投诉，我方仅留存实名信息，不私自留存、滥用用户面部生物识别信息。

同时，平台支持真人头像认证服务，您可自主选择上传本人真实头像，通过人脸识别核验头像真实性。您可完全拒绝该功能，拒绝后不影响平台基础浏览、使用功能。

2. 人工实名认证：若您无法通过智能人脸识别完成核验，可选择人工认证方式，需提交真实姓名、身份证件类型、证件正反面照片、本人手持证件照片等材料，用于人工核验身份真实性。该类信息仅用于实名认证、风险核查、争议处理，未经您明示授权，不会用于任何其他场景。

3. 实名核验适用专属场景：一是主播入驻、服务资质开通、专属房间创建；二是平台充值、付费服务下单，实名核验用于保障资金安全；三是账户资金提现，需绑定实名收款账户；四是账号封禁、冻结申诉；五是退出未成年人模式。

4. 服务考核专项核验：针对平台服务从业者、资质认证用户，我方会不定期开展专业能力考核，考核过程中将录制用户操作画面、语音及人脸影像，用于核验考核真实性。您可自主拒绝参与考核，拒绝后仅取消您的服务资质，不影响平台普通用户功能。

（三）内容浏览、搜索与下载服务场景

1. 基础浏览播放：您在浏览平台直播间、短视频、音频、社区动态、付费服务内容，以及使用播放、收藏、关注、点赞、分享等功能时，我方会依规收集设备信息与用户上网行为日志。其中设备信息包含设备型号、操作系统、Android ID、OAID、MAC地址、IMEI、IP地址、网络类型、Wi-Fi连接信息、SSID、BSSID等网络设备参数；上网日志包含浏览记录、点击轨迹、播放时长、收藏关注数据、互动行为记录等。上述信息用于保障应用正常运行、识别设备、维护账号与交易安全、分析故障以及优化服务体验。

2. 搜索功能服务：您使用平台搜索功能时，我方会记录搜索关键词、搜索时间、搜索频次、设备信息及搜索浏览轨迹，用于留存搜索记录、优化搜索匹配精度。您可随时自主清空个人搜索记录。

3. 剪切板信息调用：为便捷用户分享、跳转、口令兑换等操作，我方会在您主动使用分享功能时，临时读取设备剪切板内的链接、口令、文字信息，仅用于完成当期服务操作，不会留存、存储剪切板其他无关信息。

4. 文件下载存储：您使用平台文件、视频、素材下载功能时，经您授权设备存储权限后，可将相关内容保存至本地设备。您可随时拒绝该权限。

5. 同城定位服务：您主动开启同城、附近动态、同城匹配等功能后，经您授权定位权限，我方将收集您的地理位置信息（含粗略位置、精准定位），用于匹配同城用户、展示本地动态。您可随时关闭定位授权。

（四）社区社交互动服务场景

您在空空电竞社区开展发布动态、评论、点赞、关注、分享、私信互动等社交行为时，我方会记录您的全部操作行为数据与互动轨迹。您自主发布的图文、视频、评论、动态等内容，可随时手动删除。

（五）内容创作与媒体采集场景

您在平台拍摄、上传、发布图文、音频、视频内容，扫描二维码、录制直播素材时，需授权设备相机、麦克风、相册、存储权限。您可随时关闭上述权限，关闭后仅无法使用内容创作、扫码、语音相关功能。

（六）直播录制与服务录屏场景

用户开启直播间、专属房间、实时语音服务时，需授权相机、麦克风权限。为规范服务秩序、高效处理服务纠纷，平台上线服务过程录制功能。服务提供者可在每笔服务订单开启前，手动启动录屏录制功能，系统将全程记录服务过程中的游戏画面、操作轨迹、语音对话内容，订单正常结束后自动关闭录制。所有录屏文件全程加密存储，服务提供者无法自行查看、下载、传播，平台将留存30日基础期限；若订单出现差评、投诉、纠纷、违规举报，将自动延长留存期限。

（七）消费交易与资金提现场景

1. 消费交易信息：您在平台购买会员、虚拟道具、付费服务等商品或服务时，我方会记录订单编号、下单时间、交易金额、支付方式、支付流水、订单状态、商品信息等交易数据。同时，为保障支付安全，我方会采集用户设备IP地址，同步至第三方支付机构，用于交易风险核验。

2. 资金提现信息：服务从业者、创作者申请资金提现时，需主动填写真实姓名、身份证号码、银行卡信息、支付宝账号等敏感信息，用于完成资金结算、税费扣缴、实名核验。我方会将必要结算信息同步至合规第三方结算机构，仅用于提现履约。

（八）客户服务与维权申诉场景

您通过平台反馈意见、提交举报投诉、发起账号申诉、咨询客服问题时，我方会收集您提交的手机号、问题描述、图文凭证、沟通记录等信息，用于身份核验、问题核查、纠纷处理、结果反馈。

（九）运营活动与消息推送场景

您自愿参与平台问卷调查、赏金赛事、营销推广、福利活动等运营项目时，可能需要提交游戏账号、参赛信息、联系地址、联系方式等内容。我方会通过短信、系统通知、站内信等方式，向您推送账号安全提醒、服务更新、活动福利等信息。您可自主退订商业营销短信、关闭系统推送通知。

（十）内容展示与排序服务场景

平台内容按服务提供者的在线状态、内容发布时间、后台人工推荐，以及您主动选择的分类、价格、距离等条件展示和排序。“关注”内容依据您主动建立的关注关系筛选。上述展示与排序采用固定业务规则，不根据浏览历史、搜索记录或兴趣画像进行个性化推荐。

聊天、订单、点赞、评论、打赏及提现等消息属于与您的操作或服务相关的通知，不属于基于兴趣画像的个性化推送。平台还可由运营人员向指定用户或全体用户发送公告、活动等通知。您可通过设备系统的应用通知设置管理通知权限；商业营销短信的退订方式见本政策相关说明。平台不提供基于兴趣画像的个性化消息推送服务。

（十一）账号安全与风险防控场景

为保障用户账号、资金、信息安全，防范网络攻击、诈骗、作弊等安全风险，我方会持续采集、分析用户设备信息、网络日志、账号登录轨迹、运行进程、设备状态等数据。依据国家网络管理相关规定，用户IP对应的归属地域信息将脱敏展示在个人资料页，境内展示至省份、境外展示至国家/地区。

（十二）设备权限调用通用规则

空空电竞运行过程中所需的设备权限，均为对应功能实现的必要权限，所有权限的调用、信息采集均需获得您的明示授权。您可随时关闭、撤销权限授权，关闭后我方将终止对应信息的采集与使用。

（十三）个人信息处理通用例外规则

若您向我方提交的信息中包含第三方个人信息，您需提前取得第三方合法授权。依据法律法规，以下场景无需获得用户授权即可合法处理个人信息：维护国家安全、公共安全、公共卫生；司法侦查、起诉、审判执行；保护自然人重大合法权益；用户自行公开的合法信息；学术研究公共统计。

三、Cookie技术与第三方H5页面使用规范

（一）Cookie及同类技术使用规则

为优化访问体验、简化操作流程、保障服务稳定运行，我方在用户访问空空电竞产品时，会通过Cookie、Flash Cookie、网页信标等同类轻量化技术，存储、读取用户设备端的轻量化数据文件。您可通过浏览器、设备系统设置，自主拒绝、删除Cookie文件。

（二）第三方H5页面服务规则

为丰富服务场景、提升服务便捷性，空空电竞产品内会嵌入第三方H5页面、外部服务入口。您跳转至第三方页面后，所有信息填写、提交、操作行为均由第三方独立负责，其个人信息处理行为适用第三方隐私政策。我方不会采集、存储用户在第三方H5页面提交的任何个人信息。

四、个人信息共享、转让与公开披露规则

我方严格恪守"不随意共享、不私自转让、不违规披露"的核心原则，绝不会向无关第三方泄露、出售用户个人信息。

（一）个人信息共享规则

除我方及旗下关联主体外，我方仅在以下合规场景共享用户个人信息：

  • 1. 获得用户明示授权；
  • 2. 法定合规需求：为配合司法机关、行政监管部门依法履职；
  • 3. 关联主体协同服务；
  • 4. 第三方服务支撑：向合规合作服务商共享必要信息。

我方接入的第三方SDK服务包括：安全风控服务、支付结算服务（支付宝支付SDK）、消息推送服务、人脸核验服务（腾讯云）、定位服务（高德定位SDK）、直播音视频服务、数据统计与广告服务（仅向合作方提供去标识化、匿名化数据）。

（二）个推 SDK 信息说明

  • SDK名称：个推消息推送 SDK
  • 服务提供方：每日互动股份有限公司
